# Image replacements

The website ships with intentional visual placeholders. Replace them with optimized WebP/JPG assets and update the corresponding HTML blocks.

Recommended image set:

1. Hero: father and son in open, natural conversation; warm daylight; not posed.
2. Program: several boys building one meaningful object together.
3. Parents: both parents in calm conversation with their son.
4. Founder: Rabbi Shloimie Dratler portrait.
5. Optional module images: future-home door sign, shared bench, load-bearing bridge, meal preparation.

Use landscape images at 1600–2200 px wide, compress below approximately 350 KB when practical, and provide descriptive alt text. Obtain explicit consent for identifiable children.
