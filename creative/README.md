# Inner Leadership Creative Memory System

This directory is the repo-side index for the Inner Leadership creative/brand system.

## Source-of-truth split

- **Google Drive** stores binary assets, originals, approved images, working documents, and consent records.
- **GitHub** stores the lightweight memory, approval protocol, asset registry, prompts, and canonical Drive links that agents should read.

Do not commit large binary creative files here unless there is a technical reason. Do not make Codex search all historical assets by default.

## Required agent read order

1. [`BRAND-MEMORY.md`](./BRAND-MEMORY.md)
2. [`ASSET-REGISTRY.md`](./ASSET-REGISTRY.md)
3. [`APPROVAL-PROTOCOL.md`](./APPROVAL-PROTOCOL.md)

Do not automatically read `HISTORY` unless comparing/recovering a prior version.

## Natural-language workflow

The user should be able to say things like:

- “I like this.”
- “This is final for the landing hero.”
- “Make another one based on the approved landing-page style.”
- “Organize these.”
- “Archive the old version.”
- “Update the brand memory with what I just approved.”

The approval protocol defines what those statements mean operationally.
