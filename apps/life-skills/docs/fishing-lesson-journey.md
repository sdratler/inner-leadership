# Real Mensch lesson journey — prepared core, not mounted

Existing candidate and historical three-rank contracts are preserved. This new
four-stage core binds RM-101–RM-412 and Q01–Q48 to immutable content versions.
No actual review catalog, answer key, financial assumptions or identities are in Git.

The transactional port supports learner/attributed parent-assisted submission,
practitioner factual observation, and separate deliberate publication of a concise
summary to exact currently authorized parents. Replays return the original event;
changed retries/stale revisions conflict. A new submission requires a new observation.
Parent payloads exclude raw answers and private observations. Historical published
versions are not silently overwritten. No score, payment, attendance, employment,
media, notification or hazardous-activity permission follows from an event.

The existing practitioner-private catalog projection and closed parent projection
remain unchanged. This core has no mounted API, native store, new grant or schema.
The retained Resources/clinical case APIs are not repurposed as school enrollment.
Required admission: approved immutable learner catalog and protected teacher storage;
verified education assignment/guardian authority mapped to existing ordinary accounts;
owned encrypted native store/CAS/HTTP composition, then normal authenticated UI tests.
Draft placements, inquiry consent, a payment or a role label cannot supply that grant.

Focused synthetic repository and render tests prove only this prepared boundary.
They do not establish native persistence, ordinary login, usable preview or live acceptance.
No release, provider/send/payment/configuration/source adoption is performed here.
